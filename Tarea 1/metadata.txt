El código tiene varios errores de sintaxis y de lógica que impedirán que compile. Aquí te detallo los puntos críticos para que los puedas corregir:

1. El error de "Retorno Vacío" (Void)
En la función varianza, intentas hacer esto:
double prom = promedio(VA);

El problema: Tu función promedio está definida como void. En programación, void significa "nada". No puedes asignar "nada" a una variable double.

Solución: Debes cambiar void promedio a double promedio y usar return para devolver el valor.

2. Error al llamar a las funciones en el main
Estás escribiendo:
promedio(VA(n));

El problema: VA ya es el vector. Al poner VA(n), el compilador piensa que estás intentando llamar a VA como si fuera una función o crear uno nuevo ahí mismo.

Solución: Llama a la función simplemente pasando el nombre del vector: promedio(VA);

3. Llaves mal cerradas
En la función promedio, tienes una llave de cierre } extra antes de tiempo. Esto hace que el cálculo del promedio quede "fuera" de la función, lo que causará un error masivo al compilar.

4. Punto y coma y falta de return
En double prom = promedio(VA) falta el ; al final.

En varianza, usas size_t i, lo cual es correcto, pero en promedio usas int i. Es mejor ser consistente (usa int o size_t en ambos).

Mientras recorres los vectores, vas sumando:$\sum A$ y $\sum B$ (para las medias).$\sum A^2$ y $\sum B^2$ (para el denominador).
$\sum (A \cdot B)$ (para el numerador).Código sugerido (Estilo C/C++)C++#include <iostream>




#include <vector>
#include <cmath>
#include <cstdio> // Para usar printf

using namespace std;

void pearson_r(const vector<double>& VA, const vector<double>& VB) {
    int n = VA.size();
    double sum_A = 0, sum_B = 0, sum_AB = 0;
    double sum_A2 = 0, sum_B2 = 0;

    for (int i = 0; i < n; i++) {
        sum_A += VA[i];
        sum_B += VB[i];
        sum_AB += VA[i] * VB[i];
        sum_A2 += VA[i] * VA[i];
        sum_B2 += VB[i] * VB[i];
    }

    // Fórmula directa computacionalmente eficiente
    double numerador = (n * sum_AB) - (sum_A * sum_B);
    double denominador = sqrt(((n * sum_A2) - (sum_A * sum_A)) * ((n * sum_B2) - (sum_B * sum_B)));

    double r = (denominador == 0) ? 0 : numerador / denominador;

    // Impresión con printf como mencionaste
    printf("\n--- Resultados ---\n");
    printf("Coeficiente de correlacion Pearson (r): %.4f\n", r);
}

int main() {
    int n;
    printf("Ingrese la cantidad de elementos: ");
    scanf("%d", &n);

    vector<double> VA(n), VB(n);

    printf("Ingrese los %d valores de VA: ", n);
    for (int i = 0; i < n; i++) scanf("%lf", &VA[i]);

    printf("Ingrese los %d valores de VB: ", n);
    for (int i = 0; i < n; i++) scanf("%lf", &VB[i]);

    pearson_r(VA, VB);

    return 0;
}
