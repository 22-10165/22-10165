User prompt: Y cual es el beneficio de react especificamente
Response: El mayor beneficio de React es que permite construir aplicaciones web complejas como si estuvieras armando un juego de Lego,

Sin React, modificar un dato en la pantalla requiere buscar el elemento exacto en el HTML y actualizarlo a mano con JavaScript tradicional, lo cual

Beneficios clave de React
Arquitectura basada en componentes: Puedes dividir la interfaz en piezas independientes y reutilizables (un botón, la barra superior, el
cuadro de gráficos). Ecribes el código de una parte una sola vez y lo usas donde quieras.
DOM Virtual (Rendimiento superior): React mantiene una copia ligera del HTML en memoria. Cuando algo cambia en la app, React calcula
en milisegundos qué parte específica cambió y actualiza solo ese elemento en el navegador en lugar de recargar toda la página.
Flujo de datos declarativo: En lugar de decirle al navegador cómo cambiar paso a paso la pantalla, solo le dices a React cómo debe verse la
pantalla según el estado actual de los datos. React se encarga del resto automáticamente.
Ecosistema y mantenibilidad: Al estructurar todo en componentes, el código es infinitamente más fácil de escalar, testear y depurar en
proyectos medianos o grandes.

flex-grow (El tamaño del panel): Es una propiedad de CSS Flexbox. Si ves flex-grow: 50 en el <section class="app-pane">, le está

imagen por defecto.

 batchIndex: number;
 mean: number;
 stdDev: number;
 count: number;
}
export interface OverallStats {
 totalMean: number;
 totalStdDev: number;
 batchResults: BatchStats[];
}
// Calcula la media y desviación estándar de una lista de batches
export const calculateBatchesStats = (batches: number[][]): OverallStats => {
 if (!batches || batches.length === 0) {
 return { totalMean: 0, totalStdDev: 0, batchResults: [] };
 }
 // 1. Calcular estadísticas individuales por cada batch
 const batchResults: BatchStats[] = batches.map((batch, index) => {
 if (batch.length === 0) return { batchIndex: index, mean: 0, stdDev: 0, count: 0 };
 const mean = batch.reduce((acc, val) => acc + val, 0) / batch.length;
 const variance = batch.reduce((acc, val) => acc + Math.pow(val - mean, 2), 0) / batch.length;
 return {
 batchIndex: index,
 mean,
 stdDev: Math.sqrt(variance),
 count: batch.length,
 };
 });
 // 2. Calcular la media global uniendo todos los datos
 const allValues = batches.flat();
 const totalMean = allValues.reduce((acc, val) => acc + val, 0) / allValues.length;

 // 3. Calcular la desviación estándar global
 const totalVariance = allValues.reduce((acc, val) => acc + Math.pow(val - totalMean, 2), 0) / allValues.length;
 const totalStdDev = Math.sqrt(totalVariance);
 return {
 totalMean,
 totalStdDev,
 batchResults,
 };
};

import { processBatches, VectorEntry } from "./batchProcessor";
export function processRawSignalText(rawText: string, k: number = 2): string {
 if (!rawText || typeof rawText !== "string") return "";
 // 0. Si la entrada ya traía un resumen previo, nos quedamos solo con la parte de la señal cruda
 const cleanRawText = rawText.split("--- RESUMEN GLOBAL POR ETIQUETA ---")[0].trim();
 const lines = cleanRawText.split("\n");
 const extractedEntries: VectorEntry[] = [];
 const lineToEntryIndex: { [lineIdx: number]: number } = {};
 // 1. Extraer etiqueta y vector numérico de cada línea
 lines.forEach((line, lineIdx) => {
 const match = line.match(/^(.*?)\s*\[(.*?)\]/);
 if (match) {
 const tagLabel = match[1].trim(); // Ej: "16 L1001"
 const numbers = match[2]
 .split(",")
 .map((val) => parseFloat(val.trim()))
 .filter((val) => !isNaN(val));
 if (numbers.length > 0) {
 const mean = numbers.reduce((a, b) => a + b, 0) / numbers.length;
 lineToEntryIndex[lineIdx] = extractedEntries.length;
 extractedEntries.push({
 tag: tagLabel,
 rawVector: numbers,
 mean
 });
 }
 }
 });
 if (extractedEntries.length === 0) return cleanRawText;
 // 2. Procesar estadísticas agrupando por etiqueta sobre todos los batches
 const result = processBatches(extractedEntries, k);
 const processedLines: string[] = [];
 // 3. Formatear cada línea con el promedio del batch individual
 lines.forEach((line, lineIdx) => {
 const entryIdx = lineToEntryIndex[lineIdx];
 if (entryIdx === undefined) {
 processedLines.push(line);
 return;
 }
 const entry = extractedEntries[entryIdx];
 processedLines.push(line.replace(/\[.*?\]/, `[ ${entry.mean.toFixed(3)} ]`));
 });
 // 4. UN SOLO RESUMEN GLOBAL AL FINAL
 processedLines.push("\n--- RESUMEN GLOBAL POR ETIQUETA ---");

 Object.keys(result.tagStats).forEach((tag) => {
 const stats = result.tagStats[tag];
 processedLines.push(
 `${tag} -> Promedio Global: ${stats.globalMean.toFixed(3)} | Desviación Std: ${stats.stdDev.toFixed(3)} | Promedio
 );
 });
 return processedLines.join("\n");
}

User prompt: osea y node modules lo tengo que copiar porque aja como lo pogo mediante la interfaz web entonces
Response: ¡NO debes ni necesitas subir la carpeta node_modules a GitHub!
Esa es la razón principal por la que la página web de GitHub o los comandos se congelan o fallan. La carpeta node_modules pesa cientos de
megabytes y contiene decenas de miles de archivos pequeños.
¿Cómo funciona la web si no subes node_modules?
GitHub y la comunidad de Node/React no guardan los node_modules. En su lugar, se guardan los archivos:
1. package.json
2. package-lock.json (o yarn.lock / pnpm-lock.yaml)
Estos dos archivos tienen la lista exacta de todas las librerías que necesita tu proyecto.
Si tú u otra persona descarga el código: Solo necesita abrir la terminal y escribir npm install. NPM leerá el package.json e instalará
node_modules automáticamente en segundos en cualquier computadora.
Pasos para subir tu proyecto por la Web (Sin la carpeta node_modules)
1. Abre tu carpeta en el explorador de archivos.
2. Selecciona TODOS los archivos y carpetas (src, public, package.json, tsconfig.json, index.html, etc.) MENOS la carpeta
node_modules y la carpeta build o dist.
3. Ve a GitHub en tu navegador, entra a tu repositorio y haz clic en Add file > Upload files.
4. Arrastra los archivos seleccionados. Al omitir node_modules, se subirán super rápido y sin errores.
5. Presiona Commit changes.
